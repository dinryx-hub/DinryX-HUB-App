## 🛠️ Як розроблялася програма?

Ідея проєкту полягала в тому, щоб прибрати рутину й зробити процес налаштування чистої системи швидким та безпечним.

1. **Ядро програми (Python)**
   * **GUI (Інтерфейс):** Написано на Python за допомогою сучасних графічних елементів (`CustomTkinter` / `Tkinter`) у фірмовому стилі **Red Edition** (темний вугільний фон із неоново-червоними акцентами).
   * **Логіка завантаження:** Програма звертається виключно до офіційних серверів розробників ПО, що гарантує 100% безпеку від вірусів та стороннього «сміття».

2. **Компіляція (Nuitka)**
   * Для досягнення максимальної швидкодії та автономності код скомпільовано за допомогою комбілятора **Nuitka**.
   * Усі залежності та ресурси згруповано в один автономний `.exe` файл без потреби встановлювати Python на ПК користувача.
   * Повністю приховано вікно консолі та вбудовано фірмову іконку `icon.ico`.

3. **Дистрибуція**
   * Готові збірки та інсталятори автоматично публікуються в розділі **GitHub Releases** для прямого та зручного завантаження.

## ⚡ Запуск

Хоча програма працює автономно і не потребує встановленого Python або залежностей, якщо виникають проблеми, рекомендується завантажити файл `requirements.txt`, покласти його у свою користувацьку папку і в `cmd.exe` виконати команду:

```bash

pip install -r requirements.txt

```

## ⚡ Запуск з вихідного коду (для розробників) або авторські права, будьте людьми!!!

Якщо ви хочете протестувати або модифікувати вихідний код проєкту:

**Встановіть необхідні залежності:**

```bash

pip install requests

```

**Запустіть головний файл:**

```bash

python DinryX HUB.pyw (качаєте якщо що в релізах v.1.0.2 "Source code(.zip)" або "Source code(tar.gz)")

```

## 🛠️ Збірка у .exe (для розробників) або авторські права, будьте людьми!!!



Для комбіляції власної версії через Nuitka використовується команда:

```bash

python -m nuitka --standalone --onefile --plugin-enable=tk-inter --include-package=customtkinter --include-data-file=icon.ico=icon.ico --windows-icon-from-ico=icon.ico --windows-console-mode=disable DinryX HUB.pyw

```
